Privacy Policy

Last updated: 19 November 2026.

Loopgebra Publisher is a personal tool that publishes the owner's own videos to the owner's own TikTok account (@loopgebra).

What data is used

When the owner connects the account through TikTok Login Kit, the tool receives an access token, a refresh token and the account's open ID. It also reads the account's display name and the privacy options TikTok allows for posting. It uploads the video files and captions the owner chooses to publish.

Where data is stored

Tokens are stored only in a private file on the owner's own computer. No data is sent to any server other than TikTok's. The tool has no database, no analytics and no advertising.

Sharing

No data is sold, shared or disclosed to third parties. The tool only has one user, the account owner.

Retention and deletion

Tokens are deleted by removing the local file or by revoking the app's access in TikTok settings (Settings and privacy, Security and permissions, Apps and websites).
